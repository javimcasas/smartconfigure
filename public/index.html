SmartConfigure

Desktop tool · Windows / macOS / Linux

Push one config template to every switch in an Excel.

SmartConfigure opens an SSH session to each device listed in your spreadsheet, sends the template with its {VARIABLES} filled from that row, and keeps a full transcript per device. It runs on your machine — nothing goes through the hub.

How it works

  1. Write a template

    A plain .txt with the commands you would type by hand over SSH. Put {VARIABLE} wherever a value changes from one device to the next. Blank lines are skipped; everything else is sent verbatim, one line at a time.

    system-view
sysname {SWITCH_NAME}
commit

aaa
 local-user sshadmin password irreversible-cipher {SSH_PASSWORD}
 local-user sshadmin privilege level 3
 local-user sshadmin service-type ssh
commit

ip route-static vpn-instance _management_vpn_ 0.0.0.0 0.0.0.0 {GATEWAY_IP}
interface MEth0/0/0
 ip address {MGMT_IP} {SUBNET_MASK}
commit
save

  2. Generate the Excel, then fill it

    Choose the template in the window and press Generate Excel: SmartConfigure writes devices.xlsx next to it with the header row already in place — three fixed columns, then one column per variable the template uses. Open it, add one row per device, save. (An Excel you already have works too, as long as its header follows the same shape.)

    10.10.1.22admin••••••SW-CORE-02••••••10.10.1.110.10.1.22255.255.255.0

  3. Run — dry first, then live

    Press Run. The Excel is re-read from disk every time, so save and run again after each edit. With Dry-run ticked, SmartConfigure writes what it would send to each device and stops. Untick it and it opens one SSH session per row, sends the template line by line, and shows progress as each device finishes.

  4. Or export a SecureCRT script

    If your workstation can only reach the devices through SecureCRT, press Export SecureCRT script instead of Run. SmartConfigure writes smartconfigure-securecrt.vbs (and a .py twin) with the template already rendered for every row, and connects to nothing. In SecureCRT: Script → Run… → pick the file. It opens one SSH2 session per device, waits for the prompt after each line and leaves an <IP>.securecrt.log next to itself. The script carries the Excel credentials — treat it like the Excel.

What you get

Per-device log

A readable transcript of the whole SSH conversation, one <IP>.log per device, timestamped line by line.

report.csv

One row per device: OK or FAILED, duration, and the error that stopped it.

Dry-run

Same log format, nothing sent. A missing value in a row shows up as DRY-RUN FAILED with the exact line.

Everything lands in smartconfigure-output/ next to the Excel. Logs contain what was sent — including any password the template configures — so treat that folder as sensitive.

Format rules

  • Variables are {UPPER_CASE} in the template; the Excel column name is the same word without braces. Matching is case-insensitive.
  • Every variable needs a column. If the template uses {GATEWAY_IP} and no column is named GATEWAY_IP, the run stops before touching any device.
  • Every row needs a value for every variable, or that row is marked FAILED (the others continue).
  • Only the first sheet is read; the first row is the header.
  • Command end detection is by silence: after each line the tool waits until the device goes quiet (800ms), with a hard cap of 15s per line. A command that asks for a y/n you did not anticipate will hit the cap and fail that row — check its .log before relaunching.
  • Device-side syntax errors (% Unrecognized command, % Wrong parameter…) stop that row and mark it FAILED.

Command line

Passing --template and --excel skips the window and runs headless — same engine, same outputs. Handy for scripts and for machines without a desktop session.

smartconfigure --template template.txt --generate-excel auto
smartconfigure --template template.txt --excel devices.xlsx --dry-run
smartconfigure --template template.txt --excel devices.xlsx --out ./run-2026-09-17
smartconfigure --template template.txt --excel devices.xlsx --export-securecrt
